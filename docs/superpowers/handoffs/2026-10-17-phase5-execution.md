## spec の主な決定（計画の前提）

1. 孵化した個体は「ケージに入っていない個体」＝孵化トレイ（案A）。トレイに定員はない。
2. 孵化から1か月（ゲーム内30日）は世話なしでも弱らない（世話の値が下がらない）。
3. 孵卵器は1台ずつ状態を持つ（機種・設定温度24〜34℃・湿度）。容量は簡易6・標準12・高級24。
4. 湿度は1日2%下がり、60%未満・95%超で卵が死ぬことがある。実温33℃以上でも死ぬ。
5. 雌雄は中盤3分の1の平均温度（親 spec §5.1）。キャンドリングで段階が分かる。
6. 台帳に両親の列と3世代の家系図。手放した個体は家系の記録に残す。
7. セーブはスキーマ3のまま欄を足す。旧 `incubators`（機種の一覧）から移行する。

## 実行するときの注意

- transcriber のタスク（2〜10）は、計画の「transcriber タスク共通の前提」（`AddAnimal` の戻り値、`CageSize.Standard`、`SexKnown` など）を最初に確かめさせる。計画者が記憶から書いた点なので、違っていたら機械的な置き換えだけ許し、それ以上は止めて HQ に報告させる。
- Task 4 の `BreedingService.AdvanceEggs` への1行の追加が1行で済まなければ止めて報告、と指示してある。
- 画面のタスクは縮小した画面キャプチャ（`sips -Z 800`）で確認させ、原寸の画像を読ませない。
- Task 18 で「台帳の行をタップするとケージが開く」動きが「家系図モーダル → ケージを見る」に変わる（★15）。既存の PlayMode テストを直すことになる。
- 各タスクの後に task-reviewer を通す。EditMode・PlayMode の件数が減っていないことを毎回確かめる。
