# 段階5 孵卵器・孵化・家系 設計書

- 親の仕様書：`docs/superpowers/specs/2026-09-25-breeder-sim-design.md`（§5.1 雌雄、§7 繁殖、§8 孵卵器、§12 セーブ、§13 テスト、§14 段階5）
- 設計の話し合い：2026-09-29。要点の再確認と承認：2026-10-17。
- 完了の条件（§14）：卵を産んでから孵化するまでを一通り遊べる。PlayMode のテストで「産卵 → 孵卵器へ移す → 孵化 → ケージへ移す」が1周通る。

## 1. 決定事項

| # | 論点 | 決定 |
|---|---|---|
| 1 | 卵を孵卵器に入れる方法 | 手動で移す。移さなかった産卵床の卵も、室温のまま発生して孵化する（雌雄は室温任せになる） |
| 2 | 孵化トレイのベビー | 孵化から1か月（最初の脱皮）は世話なしでも弱らない。その後は普通の個体と同じく世話が要る |
| 3 | キャンドリングの見せ方 | 卵ごとに常に表示する |
| 4 | 33℃以上の影響 | 死亡の確率だけを上げる。奇形は作らない |
| 5 | ベビーの持ち方 | 普通の個体（Gecko）として持ち、「ケージに入っていない＝孵化トレイにいる」と扱う（案A） |

案Aを選んだ理由：1か月後の世話・成長・売却を既存の仕組みでそのまま扱える。別の型にする案（B）は同じ処理を二重に作ることになり、トレイを仮のケージにする案（C）はケージの定員やホームの数え方を崩す。
注意点：「どの個体もケージにいる」前提のコード（ビュー・コロニー・セーブ・繁殖）を洗い出して直す。

## 2. データと仕組み

### 2.1 孵卵器
- 今の `Colony.Incubators`（機種の一覧）を、1台ずつの状態を持つ型に変える：番号、機種、設定温度、湿度、どこまで計算したか（ゲーム時刻）。
- 容量：簡易6個・標準12個・高級24個（§8）。
- 設定温度：24〜34℃、1℃刻み。新しく買った孵卵器と移行した孵卵器は、28℃・湿度80%で始める。
- ショップの標準・高級孵卵器から「段階5で使えます」の表示を外し、買えば孵卵器の一覧に加わるようにする。

### 2.2 卵
- 置き場所（`EggPlace`）に「孵卵器」を加え、卵に孵卵器の番号を持たせる。
- 産卵床の卵は今までどおり室温で発生し、100%で孵化して孵化トレイへ入る。床置きの卵は、今までどおり2日で乾いて駄目になる。

### 2.3 孵卵器サービス（新規）
時間を進めるたびに、孵卵器ごとに次を計算する。閉じている間も、ゲーム内1日単位で同じ計算をする。
- 実際の温度：
  - 簡易：室温に引っ張られる（目標との差の10%、最大±2℃）
  - 標準：設定値の±0.5℃で揺らぐ
  - 高級：設定どおり
- 湿度：ゲーム内1日あたり2%下がる。
- 卵の発生：既存の計算（発生日数 28℃で60日・30℃で52日・32℃で45日、間は線形補間）をそのまま使う。中盤3分の1の温度の累計も既存の欄を使う。
- 失敗の判定（§3の数値）。

### 2.4 孵化
- 発生が100%になった有精卵が孵化する。
- 雌雄：中盤3分の1の平均温度で決める（§5.1、表の間は線形補間）。
- ベビー：
  - 遺伝子は卵の子の遺伝子を受け継ぐ。
  - 名前は「レオパ番号」とする。
  - 成長段階はベビー。雌雄はヤングになったときに判明する。性格は、ショップの個体と同じく後から判明する。
  - 母と父の番号を持つ。
  - ケージには入れず、孵化トレイに置く。
  - 孵化から1か月の「弱らない猶予」の期限を持つ。
- 孵化トレイでの操作：
  - 「ケージへ移す」：空いている最初のケージへ入れる。空きがなければ押せず、理由を表示する。
  - 「売る」：既存の卸売りの流れを使う。

### 2.5 家系の記録
- 売った個体や死んだ個体の家系図が途切れないよう、手放した個体の「番号・名前・モルフ名・雌雄」だけを残す軽い記録を加える。

## 3. 数値

| 項目 | 値 |
|---|---|
| 湿度の適正範囲 | 70〜90%（表示上の目安） |
| 湿度60%未満 | 1日ごとに10%の確率で卵が乾いて死ぬ |
| 湿度95%超 | 1日ごとに10%の確率でカビで死ぬ |
| 33℃以上 | 1日ごとに5%の確率で死ぬ（35℃以上は15%） |
| 24℃未満 | 段階4の産卵床と同じ規則（低温の累計で死ぬ） |
| 「水を足す」 | +15%、上限100%、無料 |
| 設定温度 | 24〜34℃、1℃刻み |
| 確率の計算 | 繁殖と同じ再現できる乱数を使い、1日単位で判定する |

キャンドリングの段階：

| 状態 | 表示 |
|---|---|
| 産卵から7日未満 | まだ分からない |
| 無精卵（7日以降） | 無精卵 |
| 発生 〜33% | 初期 |
| 発生 〜66% | 中期 |
| 発生 〜95% | 後期 |
| 発生 95%超 | 孵化直前 |
| 死んだ卵 | 駄目になった卵 |

- 無精卵と駄目になった卵は知らせを出し、「取り除く」ボタンで捨てられる。

## 4. 画面

### 4.1 孵卵器タブ（今の仮表示を置き換える）
- 持っている孵卵器ごとにカードを並べる。
  - 機種名と使っている数（例：「3／6個」）
  - 設定温度の −／＋ と実際の温度
  - 湿度のバーと「水を足す」ボタン。60%未満と95%超では警告の色にする。
  - 卵のマス。キャンドリングの絵で段階を表示し、タップすると説明を出す。無精卵と駄目になった卵には「取り除く」を出す。
- 一番下に孵化トレイを置き、ベビーごとに「ケージへ移す」と「売る」を並べる。
- 実装は「1画面・4ファイル以内」の単位に分ける。孵卵器カード、卵の説明、トレイで2〜3タスクの見込み。

### 4.2 そのほかの画面
- **ケージ詳細**：卵があるときに「孵卵器へ移す（全部）」を出す。産卵床の卵と床置きの卵の両方が対象。空きのある孵卵器に番号順で入れ、入りきらない分はそのまま残して「○個は空きがなく残りました」と表示する。
- **ホーム**：孵卵器ボタンに件数を添える（例：「孵卵器（卵5・トレイ1）」）。
- **台帳**：個体の一覧に「両親」の列を加える。個体をタップすると3世代の家系図（本人・両親・祖父母）を表示する。ショップで買った個体の親は「不明」と表示し、手放した個体は家系の記録から名前を出す。
- **通知**：孵化・無精卵の判明・卵の死亡・湿度の警告。段階4と同じく「最初の1件＋（ほか○件）」の形にする。
- **デバッグ**：「孵卵器に卵を追加」（有精卵3個・発生90%）を加える。画面キャプチャと実機確認で、産卵を待たずに試せるようにする。

## 5. セーブ
- 孵卵器：機種の一覧から1台ずつの状態へ移行する（28℃・湿度80%で始める）。
- 卵：孵卵器の番号を加える。
- 個体：母・父の番号と、弱らない猶予の期限を加える。ケージの番号が無い個体は孵化トレイにいるものとして読む。
- 家系の記録を加える。
- 古いセーブは、新しい欄を既定値（親は不明、記録は空）で読む。
- JsonUtility の制約（フィールドで持つ、辞書を使わない）に合わせる。

## 6. 持ち越し事項
- **スプライトキャッシュの上限**（段階4から）：キーはすでにモルフ単位に丸められている。件数に上限（例：32組）を設け、表示中でない古いものから破棄する。
- **セーブ読み込みの異常系テスト**（段階2から）：孵化で子の既知情報を作るのがこの段階のため、ここで片付ける。

## 7. テスト
EditMode を中心にする（§13）。
- 温度と雌雄（表と補間）
- 発生日数
- 湿度の低下と、乾燥・カビ・高温による失敗
- 機種ごとの温度の揺らぎ
- 閉じている間の計算（全孵卵器・全卵）
- 孵化の結果（遺伝子・両親・孵化トレイ・1か月の猶予）
- 「孵卵器へ移す（全部）」の割り振りと入りきらない場合
- セーブの移行（機種の一覧 → 1台ずつの状態）と、新しい欄の既定値
- 家系の記録と3世代の家系図
- スプライトキャッシュの上限

PlayMode では「産卵 → 孵卵器へ移す → 孵化 → ケージへ移す」を1周確かめる。最後に画面キャプチャと実機での確認を行う。
